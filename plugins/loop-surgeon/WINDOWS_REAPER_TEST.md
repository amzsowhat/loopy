# Windows / Reaper smoke test

1. Copy `Loop Surgeon.vst3` to `C:\\Program Files\\Common Files\\VST3\\`.
2. In Reaper, open **Options > Preferences > Plug-ins > VST**.
3. Confirm the standard VST3 path is present and run **Clear cache/re-scan**.
4. Insert **Loop Surgeon** on a mono or stereo audio track.
5. Test capture, automatic analysis, save/reopen restoration, and offline render.
